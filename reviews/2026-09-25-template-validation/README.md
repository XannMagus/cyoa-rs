Scope: generation-boundary R3, PROMPTS-002, ARCH-002. Explicit new user decision:
PROMPTS-003 requires semantic business-invariant validation before arbitrary prompt
overrides are authorized. Public construction remains bundled-only; source
construction and override fixtures are private. Steps 5–8 remain separate commits.

## Refinement after green

Removed legacy raw/default-only render entry points. Retained integration tests
use test-only wrappers around the new fallible API; production does not get those
unwraps. Three existing override tests moved to private unit scope with their
assertions retained and registry entries updated. This keeps arbitrary source
configuration inaccessible while preserving test coverage of future merging.

Typed source DTOs also validate bundled configuration, so defaults cannot silently
redefine their own accepted shape. Schema documentation's structural specification
comes from the Rust wire schemas, with explicit outgoing-memory fields. Compiler
mutation stays on the configuration type's inherent methods. No inner-layer
serialization/template dependencies, vendor code, filesystem loader, or automatic
model calls are introduced. Old backend evidence remains historical evidence.

Static variable analysis catches simple attributes even in unexecuted branches;
it is not a proof for dynamic lookups, imports, filters or arbitrary input. Those
can still return located render errors. Bundled contracts and expected snapshots
establish the supplied text's behavior; they do not implement PROMPTS-003.
