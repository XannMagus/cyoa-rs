# Choose restoration limits explicitly

A resumed adventure may use current configuration or its original creation
settings, so restoration requires an explicit choice and preserves original limits
separately. Every retained summary receives the active event cap, including history
reachable through rewind; increasing the cap cannot resurrect discarded events.
Generation-only cast bounds do not prune established characters or invalidate a
saved world, avoiding destructive reinterpretation of an existing adventure.
